# Security Policy

## Supported Versions

Currently, the `main` branch is the only actively supported version for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.x.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of DareToSend seriously. If you believe you have found a security vulnerability in DareToSend, please report it to us directly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email describing the issue to the maintainers. We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress fixing the issue.

Please provide as much information as possible, including:
- Type of vulnerability (e.g., XSS, SQLi, CSRF, etc.)
- Step-by-step instructions to reproduce the vulnerability
- Proof-of-concept or exploit code
- The potential impact of the vulnerability

We adhere to the principles of responsible disclosure. We ask that you do not publish the vulnerability until it has been properly addressed and a fix has been distributed.
