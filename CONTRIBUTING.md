## How to Contribute

Currently, we are not actively accepting Pull Requests for feature additions from the community to the main repository, as the project is governed tightly by the core development team to maintain architectural integrity and security.

### Bug Reports and Issues
If you encounter a bug or have a critical issue, please open an Issue on GitHub. Include detailed steps to reproduce, expected behavior, and environment details.

### Security Vulnerabilities
If you find a security vulnerability, do NOT open a public issue. Please follow the instructions in `SECURITY.md`.

## Forking the Repository
You are welcome to fork the repository for your personal or internal use, provided you adhere to the `LICENSE`. When deploying your fork, you must use your independent infrastructure and retain all branding and license files.
